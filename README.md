# DataWarehouseETLPipeline

DataWarehouseETLPipeline is a SQL Server script for building and loading a data warehouse workflow. It organizes staging, transformation, and warehouse objects in one executable SQL file.

## Features

- SQL Server database object creation
- ETL-style loading and transformation steps
- Warehouse-ready table structures
- Single-script setup for repeatable local execution

## Tech Stack

- Microsoft SQL Server
- T-SQL

## Getting Started

Open `DataWarehouseETLPipeline.sql` in SQL Server Management Studio or Azure Data Studio and run it against a SQL Server instance where you have database creation permissions.

## Project Structure

- `DataWarehouseETLPipeline.sql`: schema and ETL workflow script
